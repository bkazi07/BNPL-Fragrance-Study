# BNPL Impact on Luxury Fragrance Consumer Behavior

This repository contains the data, analysis, and visualizations used for a research project titled **"The Impact of Buy Now, Pay Later (BNPL) on Consumer Behavior in the Luxury Fragrance Market"** as part of the FIN 611 course.

## 📘 Project Overview

This study investigates how installment-based payment options such as Klarna, Afterpay, and PayPal Pay Later influence consumer purchasing behavior, specifically in the niche luxury fragrance space. The research combines internal business performance data, a consumer survey (n = 703), and industry references to explore:

- Changes in average order value (AOV)
- Conversion rates before and after BNPL integration
- BNPL user demographics and sentiment
- Return rates and satisfaction levels

## 📁 Repository Contents

| File / Folder              | Description                                                                 |
|---------------------------|-----------------------------------------------------------------------------|
| `survey_data.csv`         | Survey results from 703 fragrance buyers (BNPL usage, behavior, etc.)       |
| `sales_data.csv`          | Internal 6-month sales data before and after BNPL adoption                  |
| `bnpl_analysis.py`        | Python script that loads data, analyzes trends, and generates plots         |
| `figures/`                | Folder containing graphs used in the final research paper                   |
| `README.md`               | This file                                                                   |

## 📊 Key Visualizations

- AOV before vs. after BNPL
- Monthly order trends
- First-time vs. repeat customer breakdown (BNPL vs. non-BNPL)
- Survey response on BNPL’s influence on purchase decision
